# 赛题二 体积测量装置 · 整机模型 v011

单位 mm，Z 向上，坐标原点在底座中心；工程文件 `rig-v011.blend`。

## 总体
- 外形：400 × 400 × 489 mm（含遮光罩），满足 ≤500×500×500、≤10 kg。
- 台面（玻璃上表面）：z = 150；台面玻璃 200×200×5，台面框 240×240。
- 相机：镜头前表面 z = 400，到台面 WD = 250；相机机身 29×29×29，顶面 459，顶架 489。
- 激光：模块中心约 (-131, 0, 314)，光束与竖直约 40°，打到 z = 210 时 x ≈ -30。
- 遮光罩：后/左/右/顶/前下 3 mm 黑板 + 前帘；渲染时右/顶/前下/前帘可隐藏做剖切。

## 质量估算（目标 ≤10 kg）
- 2020 型材约 6.0 m ≈ 2.8 kg；底座 5 mm 铝 ≈ 2.2 kg（改 18 mm 胶合板 ≈1.9 kg）；
  台面托板 ≈0.8 kg；玻璃 ≈0.5 kg；玻璃框 ≈0.4 kg；背光箱 ≈0.3 kg；
  相机+镜头+激光 ≈0.5 kg；目标件 ≈0.5 kg。
- 遮光罩 3 mm 亚克力约 2.9 kg，是最大超重风险：改 2 mm 或 PVC 发泡板，控制在 2 kg 内。

## 设计注意
1. 视场校核：WD 250 + 12 mm 镜头 + 1/2.5" 传感器时视场约 117×88 mm，100 mm 件偏紧；
   若传感器更小或要留余量，换 8 mm 镜头（视场约 175 mm），或把台面降到 115、WD 提到 320（总高约 499）。
2. 相机是 29×29×29 的占位体，实际到货后按真实长宽高改 `GEO-CamBody` 与 `GEO-Lens` 即可。
3. 圆柱与五级台阶在底座上做道具；玻璃台面一次只放一个被测件（台面 200×200 放不下 L 块 + 圆柱）。
4. 背光用蓝/绿光 + 650 nm 红激光时，可用彩色相机单帧分通道同时取剪影与激光线，避免两拍切换。
